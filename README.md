# Tuk-Tuk Tracking API 

## Overview
A real-time tuk-tuk tracking system designed for Sri Lanka Police.

## Live API
https://tuk-tracking-api-production.up.railway.app/

## API Docs (Swagger)
https://tuk-tracking-api-production.up.railway.app/api-docs/

## Features
- JWT Authentication
- Role-based access
- Vehicle tracking
- GPS simulation

## Tech Stack
- Node.js
- Express
- MySQL
- Railway
